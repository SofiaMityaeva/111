# ТикетРоутер — классификация обращений и контроль SLA

Учебный проект магистратуры: веб-приложение на Python, которое по тексту обращения клиента определяет его категорию, направляет обращение в нужную группу поддержки и следит за сроками SLA.

> Компания «СетьПлюс» вымышленная. Все обращения, справочники и цифры — **синтетические** и нужны только для демонстрации.

## Проблема

В службе поддержки интернет-провайдера обращения из почты, формы на сайте и чата попадают в общую очередь. Диспетчер первой линии вручную читает каждое и выбирает группу. Из-за этого:

- обращения ждут в очереди, а срок SLA уже идёт;
- часть обращений попадает не в ту группу и возвращается назад;
- о нарушениях SLA руководитель узнаёт из еженедельного отчёта в Excel, когда исправить уже ничего нельзя.

## Решение

1. Модель машинного обучения (TF-IDF + логистическая регрессия) определяет категорию по тексту и показывает уверенность.
2. Уверенные обращения назначаются в группу автоматически, неуверенные (ниже порога 60%) уходят на проверку диспетчеру.
3. Дедлайн считается автоматически по матрице SLA «категория × приоритет», а «светофор» показывает, какие обращения под угрозой.
4. Дашборд показывает KPI, нарушения по дням и группам; правки диспетчеров используются для переобучения модели.

## Функции

| Страница | Что можно сделать |
| --- | --- |
| Старт | Сгенерировать демо-данные и обучить модель одной кнопкой, очистить базу |
| Новое обращение | Ввести обращение и сразу увидеть категорию, уверенность, группу и дедлайн; загрузить пачку обращений из CSV с отчётом об ошибках |
| Очередь | Фильтровать по статусу, группе и SLA; подтвердить или исправить категорию; менять статус; смотреть журнал правок |
| Дашборд SLA | KPI за период, график нарушений по дням, состояние SLA по группам, список «под угрозой», выгрузка в CSV |
| Модель | Accuracy и macro F1, матрица ошибок, главные слова категорий, порог уверенности, переобучение |

## Технологии

Python 3.9+, Streamlit (интерфейс), pandas (таблицы), scikit-learn (модель), plotly (графики), SQLite (база, встроена в Python), pytest (тесты). Платные API и интернет для работы не нужны.

## Установка и запуск

Нужен Python 3.9 или новее. Проверить версию: `python --version`.

```bash
# 1. Перейти в папку проекта
cd ticket-router

# 2. Создать и включить виртуальное окружение
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

# 3. Установить библиотеки
pip install -r requirements.txt

# 4. Запустить приложение
streamlit run app.py
```

Приложение откроется в браузере по адресу http://localhost:8501. При первом запуске на стартовой странице нажмите **«Сгенерировать демо-данные и обучить модель»** — это займёт несколько секунд.

## Тесты

```bash
pytest
```

27 автотестов проверяют проверку ввода, маршрутизацию, расчёт SLA, KPI на контрольном наборе, исправление категории, смену статусов и качество модели (accuracy ≥ 0,80, macro F1 ≥ 0,75).

## Формат CSV для загрузки

Кодировка UTF-8, разделитель — запятая или точка с запятой. Пример файла можно скачать на странице «Новое обращение».

| Колонка | Обязательная | Значения |
| --- | --- | --- |
| text | да | Текст обращения, до 5 000 символов |
| channel | нет | Почта, Сайт, Чат (по умолчанию Сайт) |
| priority | нет | Высокий, Средний, Низкий (по умолчанию Средний) |
| created_at | нет | 2026-10-30 14:00 или 30.10.2026 14:00 (по умолчанию — текущее время) |

## Синтетические данные

Обучающий набор собирается из шаблонов: приветствие, суть проблемы, подробности, концовка. Чтобы данные были похожи на реальные, в них добавлены опечатки, общие фразы без явной темы и примесь фраз из других категорий. Набор воспроизводим: генератор использует фиксированное зерно случайных чисел. Качество модели на реальных обращениях, скорее всего, будет ниже, чем на синтетике.

## Ограничения MVP

- Нет интеграции с реальной helpdesk-системой, почтой и чатом.
- Нет авторизации и ролей.
- SLA считается в календарном времени, без учёта рабочих часов и праздников.
- Справочники категорий и матрица SLA — допущения учебного проекта; они меняются в CSV-файлах без правки кода.
